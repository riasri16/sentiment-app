# sentiment-app
Sentiment Analysis Web App using NLP and Logistic Regression
A web app that analyzes restaurant reviews as Positive, Negative, or Neutral.

## Live Demo
[Click here to try the app](https://sentiment-app-1.streamlit.app/)

## Tech Stack
- Python
- Scikit-learn (Logistic Regression)
- TF-IDF Vectorizer
- Streamlit
